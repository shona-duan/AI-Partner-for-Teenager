Full-Stack AI Application

AI 学习助手

基于大语言模型的智能教育对话系统，支持多角色教学引导、 流式对话、作业图片识别与 Agent 状态管理。

在线体验 GitHub 源码
React + TypeScript Node.js + Express DeepSeek API Server-Sent Events 豆包视觉模型 火山引擎 TTS

核心能力

不只是套壳聊天，而是一个具备状态管理和多模态能力的教学 Agent

⚡

SSE 流式对话

基于 Server-Sent Events 的逐 token 推送，前端实时渲染打字机效果，体验接近 ChatGPT。

🤖

Agent 状态管理

Coach 模式下 AI 自动维护结构化学习计划（JSON），支持创建、推进、修改、完成等状态流转。

📷

多模态图片理解

接入豆包视觉模型，支持作业拍照 / 多图粘贴上传 → OCR 识别 → AI 教学反馈完整链路。

🎭

多角色 Prompt 系统

Tutor 引导式辅导 / Mentor 作业反馈 / Coach 学习规划，每个角色有独立教学策略。

🔊

TTS 语音合成

集成火山引擎语音合成，AI 回复可转为自然语音播放，适合低龄学习者。

💾

会话隔离与管理

按 sessionId 独立上下文，24h 自动过期清理，支持多用户并发。
